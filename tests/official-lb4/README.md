# Official LoxBerry 4 preview assets

These files were read from the official [LoxBerry 4.0.0.15 source tree](https://github.com/mschlenstedt/Loxberry/tree/4.0.0.15) for a local development preview. They retain their original authorship and licensing; they are not newly licensed under the Loxdora MIT license. `SOURCES.json` records file hashes. No downloaded file was changed. `LICENSE` contains the unmodified Apache-2.0 license from the source tag; third-party libraries retain their own license notices.

The test SDK fills the original header templates with fixture-only labels and the Loxdora navbar. It does not emulate real LoxBerry authentication or system services. Themes and widgets use the actual official core assets. These files and the entire tests directory are excluded from every installable Loxdora ZIP; the installed plugin uses the existing LoxBerry core assets and selected theme.
